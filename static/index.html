RISC-V Bulk Normalization Algorithm (RVBNA)

RVBNA is a numerical algorithm to compute approximate dot product operation.

It aims at offering a compromise between accuracy and efficiency which is suitable to scale to a large number of input elements.

Given a target number of elements, input formats and output formats, the specification is fully deterministic (all the compliant implementations will produce the same result for the same inputs).

It is specified in rvbna.adoc.
